Data Collection

Daily retail price ticks, business days only

The source file records Calgary unleaded retail price for every trading day from 1 Jan 2021 to 23 Oct 2026 — no entries on weekends, so the series follows the market's own posting calendar rather than the full civil calendar.

DP2 · Feature Engineering

Lag and rolling features, chosen from the data's own autocorrelation

Price levels stay highly correlated out to lag 10 (0.88+); day-over-day changes show momentum at lag 1 and reversal at lag 2 before fading to noise — so the feature set spans both signals without reaching past where that signal decays.

4
DP3 · Standardization & Split

Scale on the past only, split on time, never shuffle

Each feature was standardized ((value − mean) ÷ std) using statistics from the training rows alone, then applied unchanged to validation — fitting on the full series would leak future information into training.

Chronological split

Training15 Jan 2021 → 27 Aug 2025
Validation28 Aug 2025 → 22 Oct 2026
Split ratio80 / 20, no shuffling

Why no shuffling

This is a time series: shuffling would let a model train on days after the ones it's tested on — something it could never see in real use. Validation deliberately covers the most recent, most volatile 14 months, including the sharp 2026 jumps.

Outputs: train_data.csv (1,204 rows) and validation_data.csv (301 rows).

5
Modeling

Four models, one honest benchmark

Each model targets a different pattern found in the data — a near-random-walk level, non-linear jump/reversal structure, and the risk of overfitting daily noise.

ModelReason selected
Previous-Price BaselineNaive benchmark — any model must beat "tomorrow = today"
Linear RegressionLag_1 correlates ~0.99 with next price — a near-linear relationship
Decision TreeCaptures the jump/reversal thresholds a straight line can't
Random ForestAverages many trees to steady a single tree's overfitting
Gradient BoostingTargets residual errors round by round, tuned shallow against overfitting

Alternatives considered

  • Ridge / Lasso — regularizes correlated lag features
  • ARIMA / exponential smoothing — built for serial dependence; a second baseline
  • XGBoost / LightGBM — faster, often stronger boosting if more accuracy is needed

All five artifacts (including the baseline) were trained on train_data.csv and saved for reuse.

6
Validation

Measured against 301 held-out days the models never trained on

Linear Regression has the lowest error on every metric but RMSE, edging out the baseline — evidence the series is close to a random walk, where "today's price" is already a strong predictor and the extra features add a modest, real improvement.

ModelMAERMSEMedAERMSLE

Recommendation: Linear Regression — MAE 5.91¢/L vs. 6.17¢/L for the baseline. All models lag slightly behind the actual price during sharp jumps (e.g. early Oct 2026), since every feature is built from past prices only.

7
AI Governance

Checklist before this model informs a decision

Data quality

  • Validate date format & units on every refresh
  • Check gaps, duplicates, non-positive prices
  • Re-run autocorrelation checks periodically

Leakage

  • Features use only pre-prediction information
  • Scaler mean/std fixed from training only
  • Chronological split preserved on every retrain

Licensing

  • Confirm usage terms for the price data source
  • Record source & attribution with the model files

Market changes

  • Supply shocks, tax/policy shifts trigger review
  • Flag high-volatility periods as lower confidence

Monitoring

  • Track rolling MAE/RMSE vs. the baseline threshold
  • Watch feature drift vs. training distribution
  • Log every prediction with inputs & model version

Human review

  • A person reviews forecasts before any purchasing or pricing action
  • Large/anomalous predictions flagged for manual check
  • Review each quarter, and after any market shock
Key risk: the model cannot anticipate sudden jumps — it is built only from past prices. Mitigation: treat every forecast as a planning input a human reviews, never an autonomous trigger, with a wider safety margin during known volatility.
