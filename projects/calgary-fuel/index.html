Learn · Experiment · Compare

Follow the engineering workflow.

The original instructor worksheet specifies an eight-stage time-series ML exercise. Model outcomes from different tools are not a fair head-to-head accuracy ranking unless their datasets and validation conditions match.

01 Data

Kalibrate historical Calgary regular gasoline prices; source and date range documented.

02 DP1

Inspect units, date frequency, missingness, duplicates and history.

03 DP2

Engineer lagged and rolling features using past observations only.

04 DP3

Chronological split and training-only feature scaling.

05 Model

Evaluate regression methods and a persistence benchmark.

06 Validate

Compare MAE/RMSE and visualize observed versus predicted.

07 Govern

Address licensing, leakage, drift and human oversight.

08 Deploy

Working dated-price prediction interface; test response and downloads.
