# Galarza Lab v2.0 — redesigned from scratch

This version replaces the main homepage and flagship Calgary Fuel study page with newly written semantic HTML and a single new responsive stylesheet. Existing six solution applications, downloads, and project assets were preserved.

## Local testing
Unzip then open `index.html`, or run `python -m http.server 8000` in the directory containing index.html and visit http://localhost:8000/ .

## Deployment
Upload the **contents** of this directory (not a containing folder) into the `JMGR77/galarza-lab` repository root. Cloudflare Pages builds with no build command and output directory `.`. Existing professional portfolio stays separate.

## Notes
The central ChatGPT case is prominent. The six solution implementations use independent validation results and should not be interpreted as a single common benchmark. Historical observations originated from Kalibrate Full Monty; educational/noncommercial intent and attribution do not by themselves grant public redistribution rights. Check those rights before production publication.

All downloaded files and independent apps remain unchanged from the previous package; external links and their login requirements may change.
