# Galarza Lab v3.0

Fresh homepage, case study pages, project imagery and simplified publishing workflow. See `PUBLISHING_GUIDE_v3.md`.

The two core site files are `index.html` and `v3.css`; `v3.js` provides filtering and menu toggling. The complete original Calgary Fuel solution assets are preserved.

Start local testing: `python -m http.server 8000` from this directory.
